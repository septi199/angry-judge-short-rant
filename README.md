## What it does

`main.ts` writes one short, funny rant about an everyday annoyance to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`), then reads the file back and verifies it byte-for-byte before exiting. The entry is a fixed, deterministic text — no randomness, no network calls.

## The entry

> The self-checkout watched me scan the milk, then screamed 'UNEXPECTED ITEM IN BAGGING AREA' like I'd smuggled a watermelon through customs. A bored teenager shuffled over, typed a secret code, and glared at me like I was the criminal. Three items. Twenty minutes. The staffed lane sat right there, empty, laughing at me.

## Run

```sh
node main.ts
```
